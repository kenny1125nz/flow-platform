# implement

Read the task spec from the GitHub issue created by Frame, then carry it out: implement
within the scope fence, satisfy every acceptance criterion, and use the evaluation
commands to verify. Autonomous inside the contract, forbidden outside it.

Output: an `ImplementationReport` — summary, files changed, per-criterion evidence, and
the evaluation commands run. Structured data, so the downstream confirm-verify step can
check each criterion against evidence.
